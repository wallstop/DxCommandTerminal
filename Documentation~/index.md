# DxCommandTerminal

A performance-first in-game console for Unity: a toggleable terminal, a
quick-launch command bar, typed command registration, and contextual
completion. Unity 2021.3 or newer, MIT licensed.

- [Install](install.md) - add the package, open the terminal.
- [First command](first-command.md) - write and run a typed command.
- [Quick-launch bar](palette.md) - the launcher-style command bar.
- [API Reference](xref:WallstopStudios.DxCommandTerminal.Backend.Terminal) -
  generated from the Runtime sources.
